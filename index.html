GitHub connection

Advanced: token se connect karo

Token kaise banayein (ek baar):

  1. github.com/settings/personal-access-tokens/new kholo.
  2. Name: vcard-maker, Expiration: 90 days.
  3. Repository access: Only select repositories → sirf my-vcard.
  4. Repository permissions: Contents Read and write, Workflows Read and write, Pages Read-only.
  5. Generate token → token copy karke upar wale box mein paste karo.

Token sirf aapke browser mein rehta hai. Ye code, repository ya QR mein kabhi nahi jaata. Token kisi ko mat bhejna. Kabhi leak ho jaaye to GitHub settings se use turant delete kar do.
